# Template Preview

## Install

### Install node modules

```shell
npm install
```

### Install dir

`C:\transActive\bin\STISTemplatePreview`

### snapshot dir

`C:\transActive\config\database\stis\tmlibrary\snapshot`

## Run

```shell
node app.js
```

## Browser

[TMP3001](http://localhost:10099/TMP3001)
